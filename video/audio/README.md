# 配乐与音效（`audio/`）

成片的 BGM 与音效是 **原创合成** 的：`synth.py` 用 numpy/scipy 从零生成，不含任何采样、
循环包或模型输出，因此版权干净、可随仓库分发，重新运行结果完全一致（固定随机种子）。

```bash
cd video && python3 audio/synth.py     # -> audio/bgm.wav（48 kHz 立体声，37.8 s）
```

## 配乐结构（96 BPM，4/4，D 大调，1 小节 = 2.5 s）

| 时间 | 段落 | 声音设计 |
| --- | --- | --- |
| 0.0–8.8 | 片头 / 痛点 | 暖 pad + 由疏到密的「时钟滴答」，暗喻来回切窗口的焦虑；句尾一声 whoosh + 冲击进入下一段 |
| 8.6–15.5 | 入口 / 面板 | 冲击落地，D5 铃音揭幕；半拍律动（kick 1、3 + snare 2、4）、贝斯根音、加花 hat |
| 15.1–23.3 | 分支 / 变更 / Diff | 律动延续，16 分音符琶音点缀；每次转场一个短 whoosh，重点转场补一记铃音 |
| 22.9–27.3 | AI 提交信息 | 上行 riser → 逐字敲键盘的 mechanical tick（与屏幕打字同步）→ `feat(diff)…` 落定时 4 音上行铃音动机 + 高频 shimmer |
| 26.8–34.0 | 提交图 / 细节 | 最密的段落：16 分琶音 + 全律动 |
| 33.6–37.8 | 安装 / 收尾 | 回落主和弦、低音落地、铃音收束，末尾 1.6 s 淡出 |

音效时间点与画面事件对齐（转场、打字、落定），改分镜时需同步调整 `synth.py` 里的
`scene_starts` 与留言打字区间。

## 量化指标（每次生成写入 `bgm.json`）

- 48 kHz / 立体声 / 37.8 s，峰值 −1.5 dBFS，RMS −17.1 dBFS
- 短时响度 −30.1 ~ −12.1 dB（均值 −18.9），无静音窗
- 混入成片（AAC 192k）后：整轨 **−15.3 LUFS**、真峰 **−1.5 dBFS**、LRA 5.7 LU，
  接近短视频/网页播放的常见目标（约 −14 ~ −16 LUFS）

音乐审美（风格是否合口味、音量是否合适）需要人耳判断，上面只是可量化的部分。
